# 太陽系惑星ビジュアルガイド (Solar System Planet Guide)

Pythonの`tkinter`と`Pillow`を使用して作成した、太陽系の8つの惑星（水星〜海王星）の基本情報とビジュアルを確認できるデスクトップアプリケーションです。
<img width="996" height="726" alt="スクリーンショット 2026-05-31 110708" src="https://github.com/user-attachments/assets/f092b5a2-8b78-4dce-9778-ef5b325904e1" />

## 🚀 特徴
- **直感的なUI**: 左側の惑星ボタンをクリックするだけで、右側の情報パネルがスムーズに切り替わります。
- **充実した天体データ**: 各惑星の「公転周期」「太陽からの距離」「大きさ」「主な特徴」を網羅。
- **ローカル画像対応**: 外部APIやインターネット環境に依存せず、オフラインでも高速かつ確実に惑星の画像を表示します。
- **モダンな宇宙風デザイン**: 宇宙空間をイメージしたダークカラーの配色を採用。

## 🛠️ 動作環境
- Python 3.x
- Pillow (PIL)

## 📦 インストールと準備

### 1. 依存ライブラリのインストール
画像処理のために `Pillow` ライブラリが必要です。ターミナルで以下のコマンドを実行してください。
```bash
pip install Pillow
2. フォルダ構成と画像の配置
プログラムを実行する前に、スクリプト（.pyファイル）と同じ場所に planets という名前のフォルダを作成し、各惑星の画像を配置してください。

推奨するファイル構成:

Plaintext
📁 あなたの作業フォルダ/
   ├── Advanced-Planet-App.py  (プログラム本体)
   ├── README.md               (このファイル)
   └── 📁 planets/              (画像用フォルダ)
       ├── mercury.png
       ├── venus.png
       ├── earth.png
       ├── mars.png
       ├── jupiter.png
       ├── saturn.png
       ├── uranus.png
       └── neptune.png
※ 画像は PNG または JPG 形式（プログラム内の拡張子と一致させてください）に対応しています。

💻 実行方法
以下のコマンドでアプリケーションが起動します。

Bash
python Advanced-Planet-App.py
📝 惑星データについて
本アプリで表示されるデータ（距離・大きさ等）は、国立天文台（NAOJ）等の一般的な天文学データを基準にしています。

AU（天文単位）: 地球と太陽の平均距離（約1億5000万 km）を 1.00 とした単位です。
